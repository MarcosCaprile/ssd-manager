# Google-Play-Assets

- `ssd-manager-app-icon-512.png`: App-Symbol, PNG, 512 × 512 Pixel.
- `ssd-manager-feature-graphic-1024x500.png`: Vorstellungsgrafik, PNG,
  1024 × 500 Pixel.
- `phone-screenshots/*-play.png`: vier echte iPhone-Simulator-Aufnahmen der
  lokalen, vollständig fiktiven Demo-Schule, jeweils PNG, 1080 × 1920 Pixel
  (9:16). Diese Dateien sind für die Smartphone-Screenshots in Google Play.

Die Dateien sind aus den bestehenden SSD-Manager-Branding-Assets abgeleitet
und für den Google-Play-Eintrag bestimmt.
